# SequencePang 3 · Number Garden (시간 제한 없는 9장 카드)

사용자 피드백에 따라 이 프로토타입을 겹친 카드/60초 타임어택에서 **시간 제한 없는 공개 카드 9장**으로 바꿨습니다. 디렉터리와 빌드 명령 이름은 기존 파일의 업데이트 경로를 유지하기 위해 그대로 둡니다. 기존 40장 솔리테어 앱 엔트리는 변경하지 않습니다.

## 실행 파일 만들기

```sh
npm ci
npm test
npm run build
node scripts/build-tripeaks.mjs /absolute/path/sequencepang3-tripeaks-prototype.html
```

현재 Vite 설치에 포함된 esbuild로 React·CSS·Jua 폰트를 한 HTML로 묶습니다. 내려받아 브라우저에서 열 수 있습니다.

## 규칙

- 숫자 1~12의 카드 9장을 모두 펼칩니다. 위치 관계 없이 선택합니다.
- 3장 이상 등차/등비수열을 만들면 PANG으로 수집하고, 수집한 자리에 새 카드를 채웁니다.
- 증가/감소 모두 허용. 공차 0 제외, 공비 2·3·1/2·1/3.
- 선택은 무료로 되돌리거나 취소할 수 있습니다. 선택한 카드를 다시 누르면 그 카드부터 선택을 취소합니다.
- 무료 힌트는 현재 선택을 해제하고 가능한 3장의 순서를 알려줍니다.
- 수집 후 가능한 수열이 없다면 3장만 바꿔 유효한 수열을 보장하고 안내합니다.
- 목표 30장, 달성 후 현재 판과 점수를 유지한 채 30장씩 더 모을 수 있습니다.
- 시간 제한, 생명, 실패, 강제 유료 교체, 뒤 단계에서의 숫자 범위 확장은 없습니다.
- 세 시작 배치는 같은 선택을 반복하면 같은 카드를 보충하는 고정 시드입니다.
- 진행/기록은 저장하지 않습니다. 새로고침하면 처음부터 시작합니다.

## 막힘 보장의 범위

항상 현재 9장으로 만들 수 있는 3장 수열이 적어도 하나 있습니다. 플레이어가 임의로 선택한 첫 두 장이 반드시 완성된다는 뜻은 아닙니다. 잘못 시작해도 무료로 취소/힌트를 사용할 수 있으므로 계속 진행할 수 있습니다. 무작위로 난도를 올리는 단계 설계는 없습니다.

## 검증

엔진 테스트 11개: 3개 시작 배치 각각 200번 수집·이어가기(총 600회), 카드 9장 및 1~12 유지, 해법 존재, 불가능 판의 정확히 3장 교체, 이미 유효한 판 보존, 선택 복구, 잘못된 연결 거부, 목표 달성과 이어가기, 고정 시드, 불변성.

실제 번들 DOM 모의 실행: 시간 경과 24시간에도 종료 없음, 모든 카드 접근, 무료 힌트, 되돌리기, 30장 달성, 60장 목표로 이어가기, 재시작 취소, 도움말. 실제 화면 렌더링과 모바일 터치 검증은 별도입니다.
