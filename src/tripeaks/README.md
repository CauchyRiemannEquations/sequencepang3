# SequencePang 3 · TriPeaks prototype

독립 실험판입니다. 기존 40장 솔리테어의 화면과 숫자풀은 변경하지 않습니다.

## 실행 파일 만들기

프로젝트 루트에서:

```sh
npm ci
npm test
npm run build
node scripts/build-tripeaks.mjs /absolute/path/sequencepang3-tripeaks-prototype.html
```

빌드 스크립트는 현재 Vite 설치에 포함된 esbuild로 번들링하며 React, CSS, Jua 폰트를 한 HTML에 넣습니다. 결과 파일은 다운로드 후 브라우저에서 직접 열 수 있습니다. 기존 사이트의 기본 엔트리에는 연결하지 않았습니다.

## 규칙

- 카드 산 3개, 산마다 6장, 한 판 18장. 겹친 카드 숫자도 보이지만 가리는 카드를 먼저 골라야 합니다.
- 첫 두 장부터 일정한 차이 또는 비율로 수열을 만듭니다. 공차 0 제외, 증가·감소 가능, 공비 2·3·1/2·1/3.
- 3장부터 PANG으로 수집. 한 카드당 1점이며 콤보·길이 배수는 없습니다.
- 선택 중인 카드는 임시로 빠져 다음 카드를 엽니다. 한 장 되돌리기 또는 전체 선택 취소 시 정확히 복원되며 점수는 주지 않습니다.
- 18장 전부 수집하면 무료로 다음 판을 엽니다.
- 막혔을 때 새 카드판 교체는 3초가 듭니다. 교체 시 유효한 3장 이상 선택은 먼저 수집됩니다.
- 60초 종료 시 유효한 3장 이상 선택은 자동 수집, 1~2장은 취소합니다.
- 같은 배치 번호는 다음 판들까지 같은 숫자와 순서를 사용합니다. 모든 판의 숫자 다중집합은 동일합니다.
- 배치 번호별 최고 점수만 브라우저에 저장합니다. 도움말·확인창·탭 전환 중 시간도 계속 흐릅니다.

## 설계와 검증

초기 카드판마다 실제 노출 순서를 따라 3장 수열 여섯 개로 수집할 수 있는 해법을 구성했습니다. 플레이어에게는 해당 순서를 강요하지 않습니다. 다른 수열을 먼저 수집하면 막힐 수 있으며 그때 시간 비용을 내고 교체할 수 있습니다.

엔진 테스트 10개: 노출 제약, 3개 배치 각각 3판 완주, 카드풀 동일성, 취소·되돌리기, 잘못된 연결 거부, PANG 수집, 종료 시 자동 수집, 늦은 입력 차단, 교체 비용, 불변 상태.

실제 번들의 DOM 모의 실행에서 시작, 되돌리기, 18장 완주, 다음 판, 종료 정산, 최고 기록, 재시작, 교체, 도움말을 확인했습니다. 실제 브라우저 화면 및 모바일 터치는 아직 검증하지 않았습니다.
