# 시퀀스팡3

시퀀스팡3는 코코넛 테마의 **수열 마작 솔리테어 50단계**입니다.

바로 플레이: https://sequencepang3.vercel.app/

- 위에 덮인 패가 없으면 선택할 수 있습니다. 좌우 이웃은 무관합니다.
- 서로 다른 세 숫자로 등차·등비수열을 만들면 제거합니다.
- 1~10단계는 모든 합법적인 제거 경로에서 클리어가 가능합니다.
- 11~50단계는 제거 순서를 고민하며 되돌리기로 다른 길을 탐색합니다.
- 21~30단계는 같은 숫자라도 위치에 따라 열리는 패가 달라집니다.
- 31~40단계는 덮인 패와 나중에 조합할 숫자를 남겨 두는 24~30패, 2층 퍼즐입니다.
- 41~50단계는 위층 → 가운데층 → 아래층 순서로 길을 여는 24~30패, 3층 퍼즐입니다. 41단계는 1·2·3만 사용해 새 구조를 익힙니다.
- 움직이는 플레이 예시와 `cremationmath@gmail.com` 문의 버튼을 제공합니다.
- 스테이지 선택은 10단계씩 챕터를 좌우로 넘기며, 한 화면에서 10개 버튼을 확인할 수 있습니다. 다음 단계 이동과 브라우저별 클리어 기록을 제공합니다.
- [100단계 로드맵 및 50단계 구성](docs/COCONUT-ROADMAP.md)
- 홈 화면 설치(PWA), 코코넛 앱 아이콘과 오프라인 플레이를 지원합니다.
- [아이콘·설치·오프라인 구성](docs/COCONUT-PWA.md)
- 설정에서 켤 수 있는 원본 배경음악과 패·수열·완료 효과음을 제공합니다. 일반 버튼은 무음입니다
- [오디오 연결·설정·오프라인 동작](docs/COCONUT-AUDIO.md)
- [초기 코코넛 시안 기록](docs/COCONUT-PROTOTYPE.md)

## 실행과 배포

```sh
npm ci
npm run dev
npm test
npm run build
```

루트(`/`)에서 코코넛 게임이 실행됩니다. 기존 `/coconut`, `/coconut/`, `/coconut/index.html` 링크는 루트로 이동합니다. Vercel에서는 영구 리디렉션을 사용하며, 로컬 개발·정적 미리보기에서도 호환 페이지가 새 주소로 이동시킵니다.

기존 코코넛 클리어 기록은 같은 출처의 `sequencepang3-coconut-progress-v1` 저장 키를 그대로 사용합니다. 주소 이동 때문에 기록을 초기화하지 않습니다.

GitHub `main` 브랜치가 Vercel에 연결되어 있어 병합 후 자동 배포됩니다. 이전 손패 게임의 코드·스타일·용과 아이콘은 현재 소스와 배포에서 제거했으며 Git 이력은 유지합니다.
