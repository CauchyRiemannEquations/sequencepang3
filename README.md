# 시퀀스팡3 · Fixed Deck Time Attack

맨 위 카드 한 장씩 옮기며 **고정 카드 40장을 수열로 정리하는 타임어택** 실험입니다.
React + TypeScript + Vite. 서버·로그인 없이 실행됩니다.

## 플레이

- 시작 버튼을 누르면 카드가 공개되고 시간 측정이 시작됩니다.
- 숫자 1~16의 고정 풀, 카드 40장, 카드 더미 5열, 임시 보관칸 2개.
- 카드 드래그 또는 카드 → 목적지 터치. Tab과 Enter/Space도 지원합니다.
- 맨 위 카드 한 장만 이동. 빈 열에는 어떤 카드든, 보관칸에는 한 장만 놓을 수 있습니다.
- 두 장으로 연결을 시작하고 같은 차이 또는 같은 비율로 이어 놓습니다.
- 등차·등비수열 5장이 완성되면 자동 수집. **등차 6줄 + 등비 2줄, 총 40장을 정리하면 클리어**입니다.
- 증가·감소 모두 가능. 공차 0은 제외하고 공비 ×2 / ×3 / ÷2 / ÷3을 허용합니다. 실제 풀 1~16 안의 5항 등비 조합은 `1,2,4,8,16` 한 종류입니다.
- 처음 쌓인 더미는 연결된 수열이 아닙니다. 직접 이어 놓은 부분만 분홍색 선으로 표시합니다.
- 완성 전 수열의 마지막 카드를 꺼내 다른 곳에 재사용할 수 있습니다.
- 되돌리기 제한 없음. 시간은 되돌아가지 않으며 도움말·탭 전환 중에도 계속 흐릅니다.
- 잔여 숫자를 전부 분할할 수 없게 되면 되돌리기를 안내합니다.
- 콤보·추가 드로우·제한 시간 탈락 없음. 더 짧은 완주 시간에 도전합니다.
- 동일한 숫자풀의 고정 배치 3개. 최고 기록은 **배치별**로 이 브라우저에만 저장합니다.

숫자풀 실험 과정, 후보 비교, 한계는 [POOL_EXPERIMENT.md](docs/POOL_EXPERIMENT.md)에 있습니다.

## 실행

```sh
npm ci
npm run dev
npm test
npm run build
python3 scripts/analyze-pools.py
python3 scripts/make-preview.py /absolute/path/review.html
```

단일 HTML은 빌드 후 스크립트·스타일·폰트를 포함해 오프라인 검토용으로 만듭니다.
진행 중인 판은 저장하지 않습니다. 최고 기록 저장이 차단되어도 플레이는 가능합니다.

## 검증 범위

순수 로직 테스트는 모든 고정 배치를 실제 규칙으로 완주하고, 카드 보존·수열 판정·잔여 분할·타이머·기록 분리를 확인합니다. 실제 모바일 기기의 입력, 가독성, 플레이 재미는 별도 검증이 필요합니다.

현재 공개 주소 https://sequencepang3.vercel.app 는 main과 연결되어 있습니다. 이 실험은 PR #1에서 검토하며 자동 병합하지 않습니다.
