# 시퀀스팡3 · Sequence Solitaire MVP

용과 테마의 모바일 수열 + 손패 운영 퍼즐입니다.  
React + TypeScript + Vite로 동작하며 서버, 로그인, 데이터베이스 없이 브라우저에서 완결됩니다.

## 바로 플레이

https://sequencepang3.vercel.app

GitHub `main` 브랜치가 Vercel에 연결되어 있어 push 후 자동 배포됩니다.

## 핵심 규칙

- 화면에는 동시에 4개의 수열이 살아 있습니다.
- 각 줄의 규칙 이름은 표시하지 않습니다. 앞의 세 항을 보고 규칙을 추론합니다.
- 손패는 5장이고, 카드를 사용하면 NEXT 첫 카드가 들어옵니다.
- NEXT 2장을 보며 어느 줄을 먼저 밀지 판단합니다.
- HOLD 1칸과 카드 폐기 2회를 사용할 수 있습니다.
- 잘못된 숫자는 소모되지 않고 해당 줄만 짧게 흔들립니다.
- 한 줄을 완성하면 즉시 PANG 후 새로운 수열로 교체됩니다.
- 짧은 턴 안에 연속 완성하면 콤보가 이어지고 5콤보부터 DRAGON PANG이 발생합니다.
- 8개의 수열을 완성하면 테스트 런이 종료됩니다.

## MVP 수열 라이브러리

등차수열, 정수 등비수열, 제곱수열, 피보나치형만 사용합니다.  
첫 플레이의 손패 고민을 검증하기 위해 완전 랜덤 대신 설계된 카드 드로우 순서를 사용합니다.

## 실행

```sh
npm ci
npm run dev
```

배포 빌드:

```sh
npm run build
```

## 현재 검증 목표

첫 플레이 몇 분 안에 아래 판단이 실제로 생기는지 확인하는 버전입니다.

- 지금 완성할 줄과 남겨둘 줄 선택
- 같은 숫자를 어느 줄에 쓸지 선택
- NEXT를 보고 선행 배치 결정
- HOLD로 미래 카드 보관
- 막힌 손패를 제한 폐기로 정리

랭킹, 서버, 로그인, 상점, 광고, 성장 시스템은 의도적으로 포함하지 않았습니다.
