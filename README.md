# 시퀀스팡3 · 첫 플레이어블 프로토타입

React + TypeScript + Vite. 용과 테마의 6×6 수열 퍼즐 로그라이크입니다.
게임 데이터, 전투, 능력 판정은 모두 브라우저에서 처리합니다. 계정, API, 데이터베이스, 외부 폰트 요청이 없습니다.

## 바로 플레이

https://sequencepang3.vercel.app

GitHub의 main 브랜치를 Vercel 프로젝트 sequencepang3에 연결했습니다. main에 push하면 자동으로 다시 배포됩니다.

## 디자인

귀여운 용과 캐릭터, 검은 씨앗 적, 윤기 나는 크림색 타일과 핑크 효과를 사용합니다. 참고 이미지의 숫자·카드 설명은 게임 규칙에 적용하지 않았습니다. 아트 제작 정보는 [ART.md](ART.md), 폰트 라이선스는 public/fonts/OFL.txt에 있습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상 환경에서 프로젝트 폴더를 열고 실행하세요.

```sh
npm ci
npm run dev
```

Windows에서는 `START.cmd`로 실행할 수도 있습니다. 주소는 `http://localhost:5183`입니다.


휴대폰은 컴퓨터와 같은 네트워크에 연결하고, Vite가 출력하는 **Network** 주소를 Android Chrome에서 여세요. 해당 컴퓨터에 접근할 수 없는 네트워크에서는 `dist/`를 정적 호스팅에 올리면 됩니다.

```sh
npm test         # 규칙과 진행 흐름 32개 테스트
npm run build   # TypeScript 검사 + 배포용 dist 생성
npm run preview # dist 로컬 확인
```

`dist/index.html`은 웹 서버로 제공해야 합니다. 파일을 더블클릭하는 file:// 실행은 지원하지 않습니다.

## 플레이

- `PLAY` → 인접한 숫자 3개 이상을 같은 간격으로 드래그 → 손을 떼면 공격.
- 8방향 연결, 꺾인 경로, 내림차순 지원. 공차 0과 동일 타일 재사용은 금지.
- 직전 타일로 돌아가면 한 칸 되돌리기. 잘못된 숫자는 경로에 추가하지 않습니다.
- 키보드: Tab으로 보드 진입, 방향키 이동, Space 또는 Enter로 선택. `선택 확정` 버튼으로 공격. Esc로 선택 취소.
- 첫 보상은 EVEN / D2 / LONG. 이후 능력을 누적하거나 Pattern을 Lv.3까지 강화합니다.
- 조건을 세 번 만족하면 RIPE가 준비되고, **네 번째 일치 공격**에서 해당 보너스가 2배가 됩니다. 여러 Pattern은 동시에 충전·발동합니다.
- 사운드는 우측 상단에서 켤 수 있습니다. 기본은 무음. 진동은 지원 환경에서만 동작합니다.

## 구현 범위

런은 **SEED → LOCK → Mutation → BLACK SEED → MUTANT → 휴식 → THE SPLITTER**입니다.
모든 지정 Pattern, ECHO / BURST / SWAP / REROLL, JUICY / DOUBLE CORE / WILD, GROW / PRUNE / JUICE를 구현했습니다.
클리어·패배, 최고 데미지·최장 수열·RIPE 발동 수·최종 빌드, 빠른 재시작도 포함합니다.

개발 모드의 `DEBUG` 메뉴에서 즉시 승리, 능력 추가, RIPE 충전, 보스 직행, 보드 재생성, 적 HP 설정, 현재 수열 판정을 확인할 수 있습니다. 프로덕션 빌드에서는 메뉴가 제거됩니다.

## 이번 버전의 세부 규칙

기획에서 미정인 부분은 아래처럼 정했습니다. 밸런스 수정은 `src/game/abilities.ts`와 `src/game/enemies.ts`에서 가능합니다.

| Pattern | Lv.I | Lv.II | Lv.III |
|---|---:|---:|---:|
| EVEN / ODD | +40% | +70% | +90% |
| D1 / D2 / SHORT | +50% | +90% | +120% |
| FOUR | +60% | +100% | +130% |
| LONG | +75% (×1.75) | +120% (×2.2) | +150% (×2.5) |

- **중첩 계산:** 고정된 Pattern 순서로 이전 결과에 보너스를 곱하고 매 단계 반올림합니다. BASE 50 → EVEN +20 → D2 +35 = 105. ECHO는 Pattern 이후, DOUBLE CORE는 마지막에 적용합니다.
- **LONG RIPE:** 전체 배율 대신 보너스를 두 배로 합니다. Lv.I는 ×1.75 → ×2.5입니다.
- **RIPE 유지:** 게이지는 전투 사이에 유지합니다. JUICY의 일회성 잔여 효과와 ECHO 연속 공차는 새 전투에서 초기화합니다. RIPE 통계는 발동한 Pattern 개수로 집계합니다.
- **JUICY:** RIPE 발동 다음 공격에서 해당 조건이 맞으면 증폭 효과를 한 번 더 적용합니다. 조건을 맞추지 않아도 다음 공격이 끝나면 잔여 효과가 사라집니다.
- **Effect / Utility:** 최대 Lv.I이며 이미 보유한 능력은 보상에서 제외합니다. 획득 후 모든 전투에서 효과가 유지되고, SWAP / REROLL의 사용 횟수는 전투마다 초기화합니다.
- **Rare:** 엘리트 보상은 D1 / FOUR / LONG / ECHO 중 획득·강화 가능한 3개입니다. 일반 전투에서는 전체 능력 풀을 사용합니다. PRUNE은 보유하지 않은 일반 능력 2개를 제시하며, 최종 선택할 때 제거·획득을 한 번에 적용합니다.
- **잠금:** 타일에 붙어 고정되며 낙하는 잠금 위·아래 구간으로 나눠 처리합니다. BLACK SEED의 기존 잠금 확산 확률은 45%입니다.
- **REROLL:** 숫자를 새로 만들고 잠금, Wild 위치, 보스 균열은 유지합니다. SWAP은 잠기지 않은 두 타일을 거리 제한 없이 교환합니다.
- **보스:** 세로 균열은 3턴마다 이동합니다. HP ≤350에서 가로로 전환하고 그때부터 2턴마다 이동합니다. 균열 위치는 2·3·4번째 경계 안에서 움직입니다. 능력은 그대로 유지됩니다.
- **막힌 보드:** 유효한 3항 경로가 없으면 턴 소모 없이 숫자를 재정리하고 알립니다. 극단적으로 잠금이 너무 많으면 한쪽 영역의 3칸을 해제해 진행을 보장합니다.
- **WILD:** 전투 시작 시 한 개. 포함된 경로에서 가능한 1~9 등차수열을 모두 평가해 가장 데미지가 높은 해석을 선택합니다. 사용 후에는 일반 타일로 보충됩니다.
- **GROW:** Pattern을 강화합니다. Lv.III는 대상에서 제외합니다.

## 코드 구조

| 기능 | 파일 |
|---|---|
| 보드 생성·막힘 복구 | `src/game/board.ts` |
| 인접 경로·균열 검사·되돌리기 | `src/game/path.ts` |
| 등차수열·Wild 후보 판정 | `src/game/sequence.ts` |
| 데미지·미리보기 최적 해석 | `src/game/damage.ts` |
| 능력 데이터·조건·획득·보상 | `src/game/abilities.ts` |
| RIPE 충전·소모·JUICY | `src/game/ripe.ts` |
| 적 데이터·방해·보스 페이즈 | `src/game/enemies.ts` |
| 제거·중력·재생성 | `src/game/gravity.ts` |
| 전투·승패·유틸리티 | `src/game/battle.ts` |
| 7스테이지 런 진행 | `src/game/run.ts` |
| 입력·보드 표현 | `src/components/Board.tsx` |

`public/manifest.webmanifest`와 독립적인 정적 빌드 구조를 준비했습니다. PWA 오프라인 캐시 및 설치 동작은 다음 단계이며, 서비스워커는 아직 등록하지 않습니다. 런 저장·이어하기도 이번 범위에 포함하지 않아 새로고침하면 새 런으로 시작합니다.
