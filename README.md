# 시퀀스팡3 · Sequence Solitaire

카드 더미를 정리하며 등차·등비수열을 만드는 모바일 카드 솔리테어입니다.
React + TypeScript + Vite. 로그인·서버·외부 API 없이 브라우저에서 동작합니다.

## 이번 PR의 규칙

- 카드 20장을 다섯 열에 배치합니다. 모든 숫자는 보이지만 **맨 위 한 장만** 이동할 수 있습니다.
- 카드끼리 묶어서 옮길 수 없습니다. 드래그 또는 카드 → 목적지 터치를 사용합니다. Tab, Enter/Space로도 조작할 수 있습니다.
- 빈 열에는 어떤 카드든 둘 수 있습니다. 두 개의 임시 보관칸에는 각각 한 장만 둘 수 있으며 교환은 불가능합니다.
- 다른 카드 위에 놓으면 두 장으로 수열을 시작합니다. 이후 동일한 공차나 공비를 유지해야 합니다.
- 첫 배치에서 겹쳐 있는 카드들은 연결된 수열이 아닙니다. 플레이어가 실제로 이어 놓은 카드에만 분홍색 연결 표시가 생깁니다.
- 등차는 공차 0을 제외한 증가·감소 수열, 등비는 ×2 / ×3 / ÷2 / ÷3을 지원합니다.
- 두 장에서 등차와 등비 모두 가능하면 세 번째 카드로 규칙이 정해집니다. 고정된 답안이나 수열별 목적지는 없습니다.
- **5장이 연결되면 자동으로 수집**되고 아래 카드가 드러납니다. 네 줄을 모으면 클리어입니다.
- 진행 중 수열의 끝 카드를 다른 곳으로 옮겨 수열을 짧게 만들 수도 있습니다.
- 되돌리기는 제한이 없으며 완성된 수열을 수집하기 직전으로도 돌아갑니다.
- 세 가지 설계 배치를 제공합니다. 다시 놓기에서 같은 배치 재시작 / 다른 배치 시작을 선택할 수 있습니다.
- 유효한 이동만 1회로 계산합니다. 잘못된 드롭·선택·선택 취소는 이동 횟수를 늘리지 않습니다.
- 색은 장식입니다. 시간 제한·점수·자동 보충 손패·버리기는 없습니다.

이번 버전은 프리셀처럼 모든 카드가 보이는 형태를 기반으로 합니다. 뒤집힌 카드나 뽑기 더미는 없습니다. 카드의 접근 순서와 보관칸 사용에 집중하기 위한 선택입니다. 새로고침하면 초기화되며 기기 간 저장은 지원하지 않습니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run build
```

`src/game/solitaire.ts`에 순수 게임 로직, `src/App.tsx`에 입력 및 화면을 분리했습니다.
`src/game/solitaire.test.ts`는 모든 배치를 실제 이동 규칙으로 클리어하는 검증, 카드 보존, 수열 판정, 보관칸 제약, 원본 상태 불변성을 검사합니다.

모바일 뷰포트 및 터치 에뮬레이션 검증은 실제 Android/iOS 하드웨어 테스트를 대체하지 않습니다. 세 가지 배치의 완주 가능성은 검증하지만 장기적인 난이도와 재미는 플레이테스트가 필요합니다.

현재 공개 주소: https://sequencepang3.vercel.app
`main`은 Vercel 프로덕션에 연결되어 있습니다. PR 검토 단계에서는 병합하지 않습니다.
