# 시퀀스팡3 코코넛 마작 시안

2026-10-04. 기존 루트의 용과 손패 게임은 보존하고 `/coconut/`에서 별도로 실행합니다.

## 실행

`npm ci && npm run dev` 후 `/coconut/`를 엽니다. `npm run build`는 기존 루트와 새 시안을 함께 빌드합니다. `npm test`는 고정 보드의 전체 클리어 및 규칙 회귀 검사를 수행합니다.

## 규칙과 배치

- 아래층 6열×3행(18패), 위층 3열×2행(6패), 총 24패
- 폭 48, 높이 66, 가로 간격 52, 아래층 세로 간격 88, 위층 세로 간격 94의 논리 좌표를 렌더링과 판정에 함께 사용
- 위층은 가로 26, 세로 28(첫 행)·22(둘째 행)만큼 어긋나 아래층 모서리 숫자를 남김
- 위에 실제 직사각형 영역이 겹치는 패가 없으면 선택 가능. 좌우 이웃은 선택을 막지 않음 (2026-10-04 사용자 승인 변경)
- 서로 다른 숫자 세 개를 정렬하여 등차 또는 등비 판정; 같은 숫자가 포함되면 게임 규칙으로 거부
- 선택은 보드를 바꾸지 않음. 420ms 제거 연출 종료 시 한 번에 제거하고 새 선택 가능 상태 계산
- 되돌리기는 제거 직전 전체 잔존 패 목록 복원. 중력/재배치 없음
- 잘못된 선택은 제거하지 않고 550ms 후 선택만 해제
- 다시 시작/나가기는 미완료 제거 타이머 취소
- 더 이상 수열이 없으면 되돌리기 안내. 모든 선택이 클리어를 보장하는 보드는 아님

## 검증된 제거 순서

L = 아래층, U = 위층. 뒤의 두 숫자는 처음 배치 기준 행·열이며, 패 제거 후에도 좌표는 바뀌지 않습니다.

|수|위치|숫자|종류|
|--|--|--|--|
|1|U11, L21, L26|2, 4, 8|등비|
|2|L31, L16, U21|1, 3, 5|등차|
|3|L22, U13, U23|2, 3, 4|등차|
|4|U22, U12, L25|3, 6, 9|등차|
|5|L36, L11, L24|1, 2, 3|등차|
|6|L32, L12, L35|5, 7, 9|등차|
|7|L34, L15, L33|4, 6, 8|등차|
|8|L23, L14, L13|2, 5, 8|등차|

첫 수에서 U11의 2 대신 L11의 2를 써도 2·4·8이지만, 아래층 첫 행 두 번째 7이 열리는지 달라집니다.

## 범위

고정 데모 한 판, 메인/게임 방법/게임/클리어, 탭 선택·취소, 차단 이유, 되돌리기·다시 시작. 로그인/서버/광고/재화/랭킹 없음. 새 코코넛 그림은 생성된 자체 시안 자산입니다.

정량 규칙 검수와 브라우저 상호작용 검수를 구분합니다. 실제 스마트폰 기기 체감, 장기 난도·재미는 사용자 플레이 검토가 남습니다.
