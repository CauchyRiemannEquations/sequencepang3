# 시퀀스팡3 — 코코넛 수열 마작 로드맵

기준일: 2026-10-04. 1~20단계는 구현된 고정 보드이며, 21~100단계는 향후 제작 계획입니다. 후반 패 수와 층수는 플레이 검토 후 조정합니다.

## 유지할 기본 규칙

- 숫자 1~9의 서로 다른 세 패를 고릅니다. 선택 순서는 무관합니다.
- 오름차순 a<b<c에서 b-a=c-b이면 등차, b²=ac이면 등비수열입니다.
- 위층의 남아 있는 패와 실제 직사각형이 겹치면 선택할 수 없습니다. 좌우 이웃은 선택을 막지 않습니다.
- 제거 후 아래층은 제자리에 남습니다. 중력이나 재배치는 없습니다.
- 시간제한 없이 되돌리기와 다시 시작을 사용할 수 있습니다.

## 난이도를 만드는 세 가지 판단

1. 같은 숫자 중 어느 위치의 패를 제거하면 필요한 패가 열리는가.
2. 지금 제거할 수 있는 숫자를 나중의 수열을 위해 남겨야 하는가.
3. 필요한 패를 열기 위해 위층을 어떤 순서로 제거해야 하는가.

패 개수만으로 난도를 평가하지 않습니다. 가려진 숫자의 모서리를 보여 주어 계획 가능한 퍼즐을 유지합니다.

## 100단계 진행 계획

|단계|상태|주제|패 수 / 층수 시작안|핵심 판단|
|---|---|---|---|---|
|1~10|구현|첫 만남|6~15 / 1~2층|등차·등비, 선택 취소, 패 해방|
|11~20|구현|선택과 해방|18~24 / 2층|제거 위치와 다음 조합|
|21~30|계획|같은 숫자, 다른 위치|24 / 2층|어느 위치의 패를 쓸 것인가|
|31~40|계획|필요한 숫자 남기기|24~30 / 2층|적게 남은 숫자 보존|
|41~50|계획|여러 겹의 해방|24~30 / 3층|해방을 위한 선행 제거|
|51~60|계획|나뉜 구역 연결|24~30 / 2~3층|떨어진 구역의 패를 함께 활용|
|61~70|계획|등비수열의 역할|24~30 / 2~3층|등차·등비 중 유리한 조합|
|71~80|계획|두세 수 앞 계획|27~33 / 3층|제거 → 해방 → 다음 수열|
|81~90|계획|비대칭 배치|30~36 / 3층|다양한 모양에서 중요한 패 찾기|

각 10단계 구간의 마지막은 종합 퍼즐로 구성하고, 다음 구간의 첫 판에서는 부담을 낮춥니다. 같은 형태를 반복하지 않되 계단·분리된 섬·고리 등 배치가 실제 선택을 바꾸도록 설계합니다.

## 보드 제작 및 검증

- `src/coconut/stages.json`: 20개의 고정 배치, 이름, 짧은 안내, 인증된 제거 순서.
- `scripts/generate-coconut-stages.py`: 고정 시드로 1~19단계를 재현하며 기존 `board.json`을 20단계로 보존합니다. 실행 중 무작위 보드를 만들지 않습니다.
- 모든 단계의 인증된 해법을 실제 엔진으로 재생해 모든 패가 제거되는지 검사합니다.
- 1~10단계는 모든 합법적인 제거 경로를 탐색해 교착 없이 클리어 가능한지 검사합니다. 잘못된 숫자 선택은 기존처럼 거부됩니다.
- 11~20단계는 적어도 하나의 완주 해법을 보장하며, 모든 선택의 성공은 보장하지 않습니다. 더 이상 합법적인 조합이 없으면 되돌리기를 안내합니다.
- `allChoicesSolvable: null`은 미검증을 뜻하며 실패 판정을 뜻하지 않습니다.
- 해법은 개발 검증용 데이터입니다. 플레이 화면에는 정답을 노출하지 않습니다.
- 사람이 느끼는 난도와 재미는 추가 플레이 검토 대상입니다. 단계 번호는 임시 난도 배치이며 추후 교환할 수 있습니다.

## 진행과 기록

스테이지를 차례로 열고 클리어한 단계는 다시 선택할 수 있습니다. 클리어 기록은 해당 브라우저에 저장합니다. 중간 보드 상태의 이어하기, 서버 동기화, 랭킹은 이번 범위에 포함하지 않습니다.

24패는 누구나 8회 제거하므로 최소 제거 횟수 랭킹은 도입하지 않습니다. 완벽 클리어 배지와 공통 퍼즐 챌린지는 검토안이며 아직 구현하지 않았습니다.
