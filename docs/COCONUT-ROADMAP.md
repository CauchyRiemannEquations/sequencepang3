# 시퀀스팡3 — 코코넛 수열 마작 로드맵

기준일: 2026-10-08. 1~50단계는 구현된 고정 보드이며, 51~100단계는 향후 제작 계획입니다. 후반 패 수와 층수는 플레이 검토 후 조정합니다.

## 유지할 기본 규칙

- 숫자 1~9의 서로 다른 세 패를 고릅니다. 선택 순서는 무관합니다.
- 오름차순 a<b<c에서 b-a=c-b이면 등차, b²=ac이면 등비수열입니다.
- 위층의 남아 있는 패와 실제 직사각형이 겹치면 선택할 수 없습니다. 좌우 이웃은 선택을 막지 않습니다.
- 제거 후 아래층은 제자리에 남습니다. 중력이나 재배치는 없습니다.
- 시간제한 없이 되돌리기와 다시 시작을 사용할 수 있습니다.

## 난이도를 만드는 세 가지 판단

1. 같은 숫자 중 어느 위치의 패를 제거하면 필요한 패가 열리는가.
2. 지금 제거할 수 있는 숫자를 나중의 수열을 위해 남겨야 하는가.
3. 필요한 패를 열기 위해 위층을 어떤 순서로 제거해야 하는가.

패 개수만으로 난도를 평가하지 않습니다. 가려진 숫자의 모서리를 보여 주어 계획 가능한 퍼즐을 유지합니다.

## 보드 제작 및 검증

- `src/coconut/stages.json`: 50개의 고정 배치, 이름, 짧은 안내, 인증된 제거 순서.
- `scripts/generate-coconut-stages.py`: 고정 시드로 1~19·21~50단계를 재현하며 기존 `board.json`을 20단계로 보존합니다. 실행 중 무작위 보드를 만들지 않습니다.
- 모든 단계의 인증된 해법을 실제 엔진으로 재생해 모든 패가 제거되는지 검사합니다.
- 1~10단계는 모든 합법적인 제거 경로를 탐색해 교착 없이 클리어 가능한지 검사합니다. 잘못된 숫자 선택은 기존처럼 거부됩니다.
- 11~50단계는 적어도 하나의 완주 해법을 보장하며, 모든 선택의 성공은 보장하지 않습니다. 더 이상 합법적인 조합이 없으면 되돌리기를 안내합니다.
- 21~50단계는 같은 숫자 조합의 서로 다른 위치 선택이 실제로 다른 아래 패를 여는 경우가 있는지 엔진으로 검사합니다. 3층 확장에서 1~40단계 데이터는 변경하지 않았습니다.
- 31~40단계는 처음부터 열린, 하나뿐인 숫자를 성급히 쓰는 합법적 선택을 하나 이상 포함합니다. 이 선택 후에는 모든 덮개를 무시해도 남은 숫자를 수열로 전부 나눌 수 없다는 것을 검사합니다. 인증된 해법에서는 그 숫자를 3번째 이후의 제거까지 남기고, 처음에는 덮여 있던 짝과 조합합니다.
- `validation.numberPreservation`은 위 검증의 숫자·패·성급한 선택·인증된 해법의 사용 시점을 기록합니다. 생성기와 별도로 TypeScript 테스트에서 실제 엔진의 수열 판정으로 재검사합니다.
- 41~50단계의 `validation.layerUnlock`은 위층을 지워 가운데층을 연 시점과, 그 가운데층을 지워 아래층을 연 시점을 기록합니다. 모든 판에 실제로 순차 해방이 필요한 경로가 있음을 엔진으로 검사합니다.
- 41단계의 인증된 경로는 위층 세 패 → 가운데층 세 패 → 아래층 순서입니다. 숫자를 1·2·3으로 제한해 세 층 구조에 집중하도록 합니다. 46단계는 두 위층 패가 겹친 가운데층을 포함해 하나만 지워서는 열리지 않는 상황을 제공합니다.
- 세 층의 패는 최소 한쪽 모서리 숫자가 가려지지 않도록 행 간격을 넓혔으며, 숫자 영역 전체의 노출을 자동 검사합니다.
- `allChoicesSolvable: null`은 미검증을 뜻하며 실패 판정을 뜻하지 않습니다.
- 해법은 개발 검증용 데이터입니다. 플레이 화면에는 정답을 노출하지 않습니다.
- 사람이 느끼는 난도와 재미는 추가 플레이 검토 대상입니다. 단계 번호는 임시 난도 배치이며 추후 교환할 수 있습니다.

[40단계 확장 검증 기록](verification/coconut-40-stages.json): 규칙·진행·기존 보드 보존 테스트 125개와 프로덕션 빌드를 통과했습니다. 브라우저에서 31~40단계를 실제 패 클릭으로 클리어하고, 30단계 저장 기록의 31단계 연결·되돌리기·작은 화면 배치·40단계 오프라인 완주와 기록 복원을 확인했습니다.

[50단계 확장 검증 기록](verification/coconut-50-stages.json): 테스트 169개와 프로덕션 빌드를 통과했습니다. 브라우저에서 41~50단계를 실제 패 클릭으로 클리어하고, 위층 제거 → 가운데층 노출 → 아래층 노출과 되돌리기를 확인했습니다. 40단계 기록의 41단계 연결, 320px 화면 배치, 50단계 오프라인 완주·50/50 기록 복원도 확인했습니다.

## 진행과 기록

스테이지를 차례로 열고 클리어한 단계는 다시 선택할 수 있습니다. 클리어 기록은 해당 브라우저에 저장합니다. 기존 30단계·40단계 클리어 기록은 그대로 유지되어 각각 31단계·41단계부터 이어집니다. 챕터 선택에는 네 번째 **필요한 숫자 남기기**와 다섯 번째 **여러 겹의 해방** 구간을 추가했습니다. 중간 보드 상태의 이어하기, 서버 동기화, 랭킹은 이번 범위에 포함하지 않습니다.

24패는 누구나 8회 제거하므로 최소 제거 횟수 랭킹은 도입하지 않습니다. 완벽 클리어 배지와 공통 퍼즐 챌린지는 검토안이며 아직 구현하지 않았습니다.

## 플레이 안내와 문의

플레이 방법은 등차·등비·패 열기·선택 취소 네 가지를 손가락과 패 애니메이션으로 재현합니다. 일시정지·다시 보기·키보드 이동·동작 줄이기 설정을 지원합니다. 실제 게임 엔진의 수열·겹침 판정을 사용합니다. 메인의 문의 버튼은 시퀀스팡2와 같은 원형 봉투 아이콘 및 텍스트 스타일로 `cremationmath@gmail.com` 메일 작성 화면을 엽니다.
