# 코코넛 섬 오디오

사용자가 승인한 원본 음악 팩 `coconut-audio-v1`을 적용합니다. 84 BPM, D장조이며 외부 음원·샘플·사운드폰트를 사용하지 않았습니다. 원본 메타데이터는 `audio-source-manifest.json`, 출처 설명은 `public/audio/PROVENANCE.txt`에 있습니다.

## 실제 연결

- 메인·스테이지 선택: **코코넛 만의 아침**, 45.7142857초 루프
- 플레이·클리어 화면: **물결 사이의 수열**, 91.4285714초 루프
- 선택 가능한 패: 짧은 탭, 선택한 패를 다시 탭: 선택 취소
- 세 번째 패 판정: 등차·등비 성공 또는 부드러운 잘못된 조합 효과
- 위에 덮인 패: 짧은 막힘 피드백
- 실제 모든 패 제거: 3초 클리어 음악
- 처음 30단계 기록 완성: 7.1초 여정 완료 음악. 일반 클리어와 중복 재생하지 않음

다른 버튼에는 효과음을 연결하지 않습니다. 되돌리기, 다시 시작, 다음 단계, 화면 이동, 설치 안내, 도움말과 설정 버튼도 조용합니다. 원본 팩의 `undo`, `04_fresh_start`는 사용하지 않으며 배포하지 않습니다. 도움말의 자동 시연도 효과음을 만들지 않습니다.

## 설정과 수명 관리

- 처음에는 무음이며 **소리 설정 → 소리 켜기**로 시작합니다. 별도 좌측 상단 사운드 버튼은 없습니다
- 전체 소리, 배경음악, 효과음과 두 채널 볼륨을 `sequencepang3-coconut-audio-v1`에 저장합니다
- 새로고침 후에는 저장된 설정을 유지하되 새 입력 전에는 AudioContext를 만들거나 재생하지 않습니다
- 모바일 포인터·키보드 입력과 직접 설정 변경에서 컨텍스트를 깨웁니다. 소리 권한이나 로딩 실패는 게임을 멈추지 않습니다
- 탭 숨김/pagehide에서 일시정지하고 일회성 효과는 버립니다. 원래 활성화되어 있던 소리만 복귀 시 재개합니다
- 음악 전환은 0.6초 크로스페이드, 도움말·설정·설치 안내 중에는 낮은 배경음, 클리어 음악 중에는 BGM을 더 낮춥니다
- 중복 로드를 공유하고 오래 걸린 효과·취소된 화면의 결과는 버립니다. 동시 일반 효과는 세 개로 제한합니다
- Ogg를 우선 사용하며 지원하지 않는 브라우저에서는 재생 길이가 같은 WAV로 대체합니다. 플레이 BGM의 호환용 WAV만 전송 한도를 위해 28kHz 스테레오로 변환했으며, 기본 Ogg와 나머지 WAV는 원본 그대로입니다

## 오프라인 PWA

기존 PWA의 아이콘, 설치 버튼, 진행 기록 및 30단계 오프라인 게임을 유지합니다. 음악은 앱 설치 때 강제로 받지 않고, 실제 요청한 파일만 별도 콘텐츠 해시 캐시에 저장합니다. 이미 들은 음악·효과는 오프라인에서도 사용할 수 있습니다. 아직 받지 않은 음악이 오프라인에서 누락돼도 게임은 계속됩니다. 앱과 음원 캐시 버전은 독립적이며 업데이트 시 오래된 버전만 정리합니다.

## 확인

`npm test`, `npm run build`를 실행합니다. 오디오 단위 테스트는 초기 무음, 저장 값 복원·정규화, 정확한 루프 길이, 전환 경합, 로드 실패/WAV 대체, 백그라운드 중단, 효과 제한 및 취소를 확인합니다. 실제 브라우저 점검은 디코딩한 음악의 믹서 출력, 모바일 터치, 30단계 완료, 일반 버튼 무음, 작은 화면 설정 및 오프라인 재실행을 포함합니다.
